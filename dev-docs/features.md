# Image Converter: Feature List

*Created: 2026-05-01*

This document lists all planned features for Image Converter.

---

## 1. Core Features (Planned)

- **JPG to PNG conversion**: Planned for future implementation.
- **PNG to JPG conversion**: Planned for future implementation.
- **WebP conversion**: Planned for future implementation.
- **HEIC to JPG**: Planned for future implementation.
- **Batch conversion**: Planned for future implementation.
- **Quality settings**: Planned for future implementation.
- **Resolution control**: Planned for future implementation.
- **Format detection**: Planned for future implementation.

## 2. Settings and Customization (Planned)

- **Theme Toggle**: Dark / Light / System mode
- **Language Support**: English initially, expandable
- **Notification Settings**: Configurable alerts

## 3. Premium Features (Future)

- **Ad-Free Mode**: Remove all ads for premium subscribers
- **Advanced Tools**: Premium-only features TBD based on user feedback

## 4. Privacy and Compliance

- **No Login Required**: App works fully offline
- **Local-Only Storage**: All data stays on-device
- **No Unnecessary Permissions**: Only request what is needed
- **Privacy Policy**: Will be hosted externally and linked in-app
